# Java Lessons

Repositório criado para registrar nossas aulas, exercícios e projetos enquanto estudamos Java juntos.


## Como vamos estudar

Cada assunto terá:

-  Uma breve explicação
-  Exemplos de código
-  Exercícios
-  Um desafio

## Conteúdo

- Introdução ao Java
- Variáveis
- Operadores
- Condições
- Laços de repetição
- Métodos
- Classes e Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Projetos práticos
