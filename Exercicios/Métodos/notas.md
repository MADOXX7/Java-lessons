# Métodos Java

Métodos Java são blocos de código que executam uma tarefa específica. Um método nos permite reutilizar código, melhorando a eficiência e a organização. Todos os métodos em Java devem pertencer a uma classe. Os métodos são semelhantes às funções e expõem o comportamento dos objetos.

> Um método permite escrever uma parte da lógica uma vez e reutilizá-la sempre que necessário no programa. Isso ajuda a manter seu código limpo, organizado e mais fácil de entender e gerenciar.
